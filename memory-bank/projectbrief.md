# Project Brief

## Project Goal
To build a Cline Memory Bank for the k8s-dra-driver project. This memory bank will serve as a persistent store of knowledge and context, enabling Cline to effectively resume work after each reset.

## Core Requirements
*   Create a directory named `memory-bank` in the project root.
*   Create six core Markdown files within the `memory-bank` directory:
    *   `projectbrief.md`
    *   `productContext.md`
    *   `activeContext.md`
    *   `systemPatterns.md`
    *   `techContext.md`
    *   `progress.md`
*   Populate each file with initial content based on the project context and common software engineering practices.
*   Maintain and update the memory bank as the project evolves.
